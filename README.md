# Debt Risk Prediction 📊

## 📌 Project Overview

Debt Risk Prediction is a machine learning project that analyzes
economic indicators to identify patterns associated with debt risk.

The project explores different machine learning algorithms and
compares their performance on economic and financial data.

## 🎯 Problem Statement

Economic conditions such as government debt, revenue, expenditure,
GDP growth, and current account balance can provide useful signals
when analyzing a country's financial risk.

This project aims to use historical economic indicators to build
machine learning models that can help identify debt-related risk.

## 📊 Dataset

The dataset contains economic indicators such as:

- GDP Growth Rate
- Gross Debt (% GDP)
- Current Account Balance
- Government Revenue
- Government Expenditure
- Net Lending / Borrowing

The data is used to train and evaluate machine learning models.

## 🤖 Machine Learning Models

The project explores and compares:

- Logistic Regression
- Support Vector Machine (SVM)
- Random Forest
- XGBoost

Logistic Regression is used as an interpretable baseline, while
tree-based and other classification models are evaluated for
comparison.
